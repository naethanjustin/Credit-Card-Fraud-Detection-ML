# Credit Card Fraud Detection using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to detect fraudulent credit card transactions. A Logistic Regression model is trained on a real-world dataset to classify transactions as genuine or fraudulent.

---

## 🎯 Objectives

- Detect fraudulent credit card transactions.
- Perform data preprocessing and feature scaling.
- Train a Logistic Regression model.
- Evaluate model performance using Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

---

## 🛠 Technologies Used

- Python 3.14
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Visual Studio Code

---

## 📊 Dataset

**Dataset:** Credit Card Fraud Detection Dataset

**Source:** Kaggle (Machine Learning Group - ULB)

- Total Transactions: 284,807
- Fraud Transactions: 492
- Features: 31

**Note:** The dataset is not included in this repository due to its size. Download `creditcard.csv` from Kaggle and place it in the project folder before running the code.

---

## 🤖 Machine Learning Model

- Logistic Regression
- Feature Scaling using StandardScaler

---

## 📈 Evaluation Metrics

- Accuracy

- Confusion Matrix
